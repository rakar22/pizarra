# Pizarra

Análisis profesional de apuestas de fútbol. Escritorio de analista: modelo Poisson contra cuotas de mercado, valor, clasificaciones y un Scout táctico.

## Qué hace

- **Agenda** de partidos (Premier League, LaLiga, Serie A, Bundesliga, Ligue 1, Champions, Europa League, MLS, Liga MX, Liga Profesional, Brasileirão…).
- **Modelo Poisson** (ataque/defensa + forma + ventaja local) frente a cuotas 1X2 y O/U 2.5.
- **Valor**: mercados donde la probabilidad del modelo supera la implícita del mercado.
- **Scout**: briefing táctico bajo demanda (no es un tipster).
- **Cartera** local: bankroll, unidad y Kelly a un cuarto.

18+. Juego responsable. No es consejo financiero ni de apuestas.

## Datos

Fuentes públicas (lista [public-apis/public-apis](https://github.com/public-apis/public-apis) y endpoints abiertos):
